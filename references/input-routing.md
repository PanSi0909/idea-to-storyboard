# 输入路由

先识别素材成熟度，再进入最早缺失步骤。

| 用户输入 | 进入位置 | 首要动作 |
|-|-|-|
| 一句话想法、主题、课程作业 | 故事发现 | 提炼命题，追问决定方向的缺口 |
| 零散片段 | 故事发现 | 区分已知事实与空缺，不替用户填关键选择 |
| 8句话故事或故事设计卡 | 逻辑核查 | 检查因果、时限、即时损失和核心选择 |
| 梗概或完整剧本 | 故事搭建/逻辑核查 | 反向提取8句话与故事卡，请用户确认核心五项 |
| 150秒结构 | 一致性设计 | 先检查七拍、信息密度和阻碍升级 |
| 角色设定、场景设定或参考图 | 一致性设计 | 提炼稳定识别锚点与禁止变化 |
| 已有分镜 | 分镜验收 | 只核查时长、单一任务、升级和一致性；不重写核心 |
| 飞书/在线文档链接 | 当前阶段检测 | 先读后判断；只有明确授权才写回 |
| Word、PDF、PPT、Markdown、图片 | 当前阶段检测 | 提取约束；把示例与用户故事分开 |
| 用户指定某一步 | 指定步骤 | 直接进入，不强制重跑前序 |

信息充分时连续完成。信息不足时只问会影响主角、即时损失、错误办法或关键选择的问题。
