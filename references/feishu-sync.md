# 飞书同步

仅在用户明确要求写入飞书时使用当前环境可用的飞书文档能力；本 Skill 不假设固定工具名。

## 操作顺序

1. 解析 Wiki 链接到实际文档，并读取相关章节；编辑前获取包含块标识与样式的版本。
2. 判断文档中哪些流程产物已经完成，避免重复新增。
3. 小范围修改使用“原文 → 修订建议 → 最终稿”或文档支持的修订/批注能力；禁止静默覆盖用户原文。
4. 新增内容放在对应标题下，沿用文档原有标题层级、术语与字段。
5. 写入后重新读取受影响章节，核对内容、位置、格式与版本。
6. 向用户说明新增了什么、修改了什么、原文如何保留；失败时不要声称完成。

## 边界

- 读取链接不等于获得写入授权。
- 只修改用户明确放入范围的文档。
- 不把访问令牌、私人链接参数或账户信息写入 Skill、案例或日志。
- 导出案例时移除与教程无关的个人信息，并在案例顶部注明来源与授权范围。
