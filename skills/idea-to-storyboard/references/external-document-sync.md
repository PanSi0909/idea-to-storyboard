# 外部文档同步

本 Skill 的创作流程与文档平台无关。仅在用户明确要求写入，且当前环境具备对应平台的连接能力时执行同步；作者本人使用飞书，但其他在线文档、本地文档或内容管理工具同样适用以下规则。

## 操作顺序

1. 识别链接或文件类型，读取用户指定的文档或章节；平台存在知识库、容器或快捷方式时，先解析到实际文档。
2. 判断哪些流程产物已经完成，标记“已完成”，避免重复新增。
3. 小范围修改使用“原文 → 修订建议 → 最终稿”或目标平台支持的修订、建议、批注能力；禁止静默覆盖用户原文。
4. 新增内容放在对应标题下，沿用文档原有标题层级、术语和字段。
5. 写入后重新读取受影响章节，核对内容、位置、格式与版本。
6. 当前环境不能直接写入时，输出可复制或导入的 Markdown，并明确说明需要用户手动导入。
7. 向用户说明新增了什么、修改了什么、原文如何保留；失败时不要声称完成。

## 边界

- 读取链接或文件不等于获得写入授权。
- 只修改用户明确放入范围的文档。
- 不把访问令牌、私人链接参数或账户信息写入 Skill、案例或日志。
- 导出案例时移除与教程无关的个人信息，并在案例顶部说明其为原创示例或获得了公开授权。
