# 150秒七拍

| 时间 | 节拍 | 必须完成的功能 |
|-|-|-|
| 0—5秒 | 钩子 | 用异常、风险或选择题打断日常 |
| 5—20秒 | 人物目标 | 明确今天必须完成什么及时间限制 |
| 20—35秒 | 意外闯入 | 让原计划失效或让不行动也产生代价 |
| 35—75秒 | 第一次行动 | 主角主动使用错误办法，短暂获得安全感 |
| 75—105秒 | 压力升级 | 旧办法开始伤人，代价从抽象变得可见 |
| 105—135秒 | 关键选择和高潮 | 主角第一次做出与旧办法相反的行动 |
| 135—150秒 | 结果和无台词余味 | 让外界给出克制回应，留下未完全解决的余味 |

## 信息密度

每20—30秒至少加入一次有效新信息。有效意味着它改变观众对目标、关系、代价或下一步行动的理解；换景、重复台词和纯气氛不算。

## 阻碍升级检查

为每次阻碍标注至少一项：信息、关系、代价、行动方式。若一次阻碍没有任何变化，只指出它是重复阻碍，并建议删减或合并；不要擅改锁定的关键选择。
